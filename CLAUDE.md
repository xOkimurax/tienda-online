# CLAUDE.md - Tienda Online

## Ruflo Agents Disponibles
- ruflo-core: foundation, health checks, status
- ruflo-swarm: coordinate multiple agents as a team
- ruflo-autopilot: autonomous agent loops
- ruflo-rag-memory: smart retrieval, pattern memory
- ruflo-knowledge-graph: entity relationship maps

## Stack
- React 19 + Vite
- Tailwind CSS v4
- Supabase (Auth, DB, Storage)
- React Router v7
- Zustand

## Reglas
1. Leer SPEC.md antes de empezar cualquier tarea
2. Usar Supabase MCP para gestionar DB, auth, storage
3. Precios en Guaraníes (INTEGER, sin decimales)
4. Formatear: Gs. 50.000
5. Mobile-first responsive
6. Componentes reutilizables en src/components/
7. No inventar features fuera del spec
8. Testear cada feature antes de pasar a la siguiente
